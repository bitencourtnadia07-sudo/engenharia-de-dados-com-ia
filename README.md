# 🤖 Como a Inteligência Artificial pode auxiliar a Engenharia de Dados

## 📖 Sobre o projeto

Este projeto foi desenvolvido como parte do desafio da DIO utilizando o NotebookLM como ferramenta de aprendizagem ativa.

O objetivo deste estudo foi compreender como a Inteligência Artificial pode apoiar profissionais de Engenharia de Dados em suas atividades, explorando aplicações práticas, automações, benefícios, limitações e os impactos da IA nos processos modernos de dados.

A partir da curadoria de fontes técnicas, foram analisados conceitos fundamentais da Engenharia de Dados, como pipelines, ETL, ELT, Data Warehouse, Data Lake, qualidade de dados e arquiteturas modernas, relacionando esses conhecimentos às possibilidades oferecidas pela Inteligência Artificial.

O NotebookLM foi utilizado como ferramenta de apoio para organização do conhecimento, análise das fontes, geração de resumos, criação de perguntas estratégicas e consolidação dos aprendizados.

---

# 🎯 Objetivos

- Compreender o papel do Engenheiro de Dados em ambientes modernos.
- Identificar como a Inteligência Artificial pode auxiliar atividades da Engenharia de Dados.
- Explorar aplicações de IA em pipelines, qualidade de dados e automação de processos.
- Entender conceitos relacionados à preparação de dados para aplicações de Inteligência Artificial.
- Desenvolver um material de estudo e revisão para minha jornada de aprendizado em Engenharia de Dados.
